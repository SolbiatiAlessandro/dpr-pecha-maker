Texts in this volume

Each text begins on a new folio front. A blank back is inserted when needed and counts toward the continuous Arabic page numbers. Tibetan folios restart at each text’s chosen number. Side names replace the chosen inside notes. This volume workflow is a web addition, not verified original Windows behavior.

Pasting keeps formatting and supported inline images when your browser supplies RTF. Otherwise it pastes plain text.

Copy and Cut include readable text and RTF with fonts, sizes, colours and inline images, where the browser supports it. Formatted Cut keeps the following text’s style. Turn this off to copy or cut raw formatting codes.

Typeover replaces the next character, including its Tibetan stack or vowel marks. It stops at formatting marks and line breaks. Paste and input-method composition keep normal insertion; newly typed vowel marks extend the preceding character.

Formatting buttons insert a mark at the cursor. It applies until another mark changes it. In the editor, Ctrl/Command+Enter inserts a page break; Ctrl/Command+\ inserts a fixed shad.

Format selected text

Select text above. Change only the attributes you choose; blank fields keep mixed formatting. With no selection, formatting begins at the cursor. Whole-text size overrides individual sizes until cleared.

Font choices include names used in this document. Choose “Other font…” to enter a local font name. If it is unavailable, the browser uses a fallback.

Images

Images are embedded in your saved document as PNG. Inline images move with the text; an image yi-go follows the yi-go page rules.

PNG resolution metadata is read when available. Other images default to 96 DPI; adjust DPI to set physical size. Ignore DPI uses 96 DPI here; Windows uses reference-display units, so exact sizing can differ. Page images stay on the chosen volume page number when text changes. Native image import is experimental, including 1.0 inline records and 1.1 inline/yi-go/page images. Check every position and size; unsupported records are reported.

Text size

All main text changes size together, keeping fonts, bold and colours. Numbering and margin notes have their own sizes.

Root, commentary and heading styles

Choose your own fonts and bold settings. Changes update every marked passage. A whole-text size overrides role sizes until cleared. Roles are a web feature; original Windows named styles are unverified.

Choose Tibetan characters

Choose a character to insert at the text cursor or replace selected text. Combining marks are shown on ཀ to make them readable; only the chosen mark is inserted. These are Unicode characters, not legacy Windows font codes.

Browser recovery

Recovery is stored only in this browser, not beside your source file. Timed recovery also saves when leaving the page where possible. Off keeps the previous recovery but stops updating it. Use Save for a lasting file copy.

Reuse text, layouts and annotations

Windows templates contain layout only. Fonts and web styles are not preserved; automatic first-line positioning becomes fixed. Keep a full Save for your complete web document.

Windows template export notes

    Revert restores the document opened in this session or the checkpoint captured when you press full Save. Cancelling the download does not undo that checkpoint. Separate-settings downloads do not change it. Revert does not reread an external file. Browser recovery keeps the most recent edits separately.

    Selected-settings downloads are web .pecha files. Loading a layout keeps your current text and annotations; loading annotations keeps text and layout. Full Save includes everything.

    Compatibility and unfinished features

    This is an independent first-pass recreation, not an exact Windows port. Unicode fonts can produce different line and page breaks.

    Available: Title/Fancy/Body layouts, paper orientation and margins, folio and page starts, side labels, automatic marks, text formatting, reusable web templates, PDF reading and two-sided print preparation.

    Still incomplete: native image import (1.0/1.1 support is experimental; real native image specimens remain unverified), full RTF fidelity, older and multi-record TibetDoc import, TibetDoc export, Windows legacy keyboard maps, and full native PXP/PXC/PXA export. Experimental Windows PXT layout export is available with explicit conversion notes. Full-page mode is available, but exact Windows layout parity remains unverified. Legacy imports do not preserve every setting or image.

    Multi-text numbering resets, section names and reordering are available under “Texts in this volume.” They are web additions. Exact original Tibetan label facing and several mark details await runtime verification.

    The global size, configurable text roles and extra folio rotation choices extend the web workflow; they are not claims about original Windows features.
